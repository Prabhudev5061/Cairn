# Roadmap
0. Foundation: scaffold, security, typed IPC, tests, CI on Windows + Ubuntu, agent files.
1. Walking skeleton: open vault, file tree, CodeMirror editor, save, create/rename/delete, watcher, app shell UI.
2. Live-preview editor: hidden syntax, inline/block KaTeX, autocomplete (markdown + LaTeX), vim mode and ex commands.
3. Linking and index: wikilinks, aliases, headings, block refs, embeds, tags, backlinks, rename-updates-links, search.
4. Graph view: global and local, filters, keyboard navigation.
5. Other formats via FormatPlugin: Org-mode, Typst, AsciiDoc.
6. Polish and release: command palette, themes, templates, daily notes, export, installers (NSIS, AppImage, deb).
